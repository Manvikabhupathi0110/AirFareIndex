How another system consumes the API

1
Send GET request
A statistical system requests an endpoint.
2
Receive JSON
The published data is returned in a machine-readable format.
3
Integrate
The consumer can store, analyse, or display the response.

1. Published index

Returns one date or a date range of published daily index values.

GET /api/v1/index?date=2026-09-20

Also supports ?from=YYYY-MM-DD&to=YYYY-MM-DD and ?limit=1..366.


    


    

      

        
2. Index traceability
Explains how a selected index is decomposed across route, airline, and booking window.

        
      

      GET /api/v1/traceability?date=2026-09-20
      

    


    

      

        
3. Dataset metadata
Returns the dataset definition, reference period, base period, methodology, and source classification.

        
      

      GET /api/v1/metadata
      

    


    

      
Example integration

      
A consumer can call the endpoint from ordinary application code:

      
fetch('https://airfare.hatchable.site/api/v1/index?date=2026-09-20')
  .then(response => response.json())
  .then(data => console.log(data.data));

    


    

      
Prototype data notice

      
The current published index uses synthetic airfare observations for demonstration. The API interface is real and publicly callable; the current values are not official NSO/RBI statistics.
